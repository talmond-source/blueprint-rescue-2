# Blueprint Rescue 2.0

A 3D Cell City DNA game (Mr. Almond): DNA, repair, transcription, translation, protein delivery, mutations, and a mitochondrial family mystery. 9 levels in 3 acts.

- `index.html` is the Chromebook edition, built for student devices.
- `mobile/` is the app edition: add it to a home screen and it runs full-screen, with touch controls and offline play after the first visit.

Students can press **Save** at any time for a 16-character code that brings them back to the start of the level they're on.
